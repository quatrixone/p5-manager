# Contributing

Bug reports and pull requests are welcome. A few rules keep the repository
safe to host and to use.

## Content that does not belong here

Pull requests, issues, comments and attachments must not contain:

- Sony firmware, system files, SDK files, source code or documentation
  marked confidential.
- Encryption or signing keys, licence files, account tokens, passwords, or
  console identifiers (IDPS, PSID, account IDs).
- Games, game dumps, package files, or links to places that offer them.
- Binaries of other people's projects. Link to the author's release; the
  application downloads third-party tools from their source.

Anything like that is removed, and the history is cleaned where needed.

## What we do not help with

Running or obtaining software you do not hold a licence for. See
[LEGAL.md](LEGAL.md).

## Code

- Run the tests before opening a pull request: `npm test` in `backend/` and
  in `frontend/`.
- Keep changes focused; say in the description what you checked and how.
- By contributing you agree that your contribution is licensed under the
  MIT licence of this project and that you have the right to submit it.
